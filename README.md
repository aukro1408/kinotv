# Пацюк Кино · TV 🐾📺

ТВ-версия каталога фильмов и сериалов — отдельное приложение с нуля под пульт.
Организация в духе Lampa: левое икон-меню, экраны, ряды карточек.

**Живая версия:** https://aukro1408.github.io/kinotv/

## Что внутри

- **Сайдбар** — Главная, Фильмы, Сериалы, Поиск, Избранное, История, Настройки
- **Главная** — hero + ряды (В тренде, Сейчас в кино, Топ, Сериалы)
- **Каталоги** — Фильмы / Сериалы с табами (Популярные, Топ, Скоро…)
- **Поиск** — экранная клавиатура (RU+EN)
- **Страница фильма** — постер, инфо, актёры, «Смотреть», «В избранное»
- **Источники** — Lumio, Filmix 4k, Alpac, Торренты (портированы из «Кино»)
- **Плеер** — встроенный (HLS через hls.js) + VLC через intent (без потери страницы)
- **Пульт** — пространственная D-pad навигация, память фокуса, Back

## Масштаб

Вся вёрстка в `em`, базовый `font-size = высота экрана / 45` (как в Lampa) —
одинаково на 720p и 1080p. Постеры `w500`, бэкдропы `w1280`.

## Общие данные с «Кино»

Один origin (`aukro1408.github.io`) → один `localStorage`:
ключи `kino.*` общие — TMDB-ключ, Filmix-токен, TorrServer, избранное и история
подхватываются автоматически. Вводить можно в любом из приложений.

## Структура

Всё в одном `index.html`:
- CSS — сайдбар, карточки, ряды, экраны, плеер, шторки
- JS-ядро — LS/state, TMDB-клиент, навигация
- Экраны — главная, каталог, поиск, фильм, избранное/история, настройки
- Источники — портированный блок из «Кино» (`vw*`: Lumio/Filmix/Alpac/торренты)
- Плеер — `openPlayer`/`closePlayer`
